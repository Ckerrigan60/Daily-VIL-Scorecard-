§02

Set these three things once — or nothing will match

Your file uses numbered accounts (4000, 5200…), splits revenue into classes, and reports on an accrual basis. If any of these are off in your settings, your reports will look different from your accountant's no matter how you run them. Check all three first.

1

Turn on account numbers

This is why your lines read "4000 Construction Revenue" instead of just "Construction Revenue."

Gear › Account and settings › Advanced › Chart of accounts › toggle Enable account numbers & Show account numbers
2

Turn on class tracking

Powers the by-Class report. Each transaction gets tagged Construction, Enhancements, or Maintenance.

Gear › Account and settings › Advanced › Categories › Track classes = On › Assign one to each row
3

Default to accrual basis

Your Balance Sheet has A/R, A/P and deferred revenue — those only appear on accrual. Cash basis hides them.

Gear › Account and settings › Advanced › Accounting › Accounting method = Accrual
§03

The recipes

Every QBO report opens the same way: Reports in the left menu → open the report → hit Customize (top right) → set the options below → Run report. The Customize panel has four sections: General, Rows/Columns, Filter, Header/Footer.

Balance Sheet

Tab 1 · Position
Reports › Balance Sheet
  1. Set the report date
    In General › Report period, choose As of and set the date to your month-end — e.g. 04/30/2026.
  2. Add the prior-month comparison column
    In Rows/Columns › Compare another period, tick Previous period (PP). That produces your second column, "As of Mar 31, 2026 (PP)."
  3. Confirm accrual basis
    In General › Accounting method, select Accrual.
  4. Show all active rows
    In Rows/Columns, set Show non-zero or active only → Rows = Active so zero-balance accounts still list (your file shows them).
    Shortcut: QBO also ships a canned Balance Sheet Comparison report that has the PP column pre-built — use it and skip step 2.

Profit & Loss — Summary

Tab 2 · Performance
Reports › Profit and Loss
  1. Set the trailing 13-month window
    In General › Report period, pick Custom and enter 04/01/2025 to 04/30/2026. Thirteen months lets April 2026 sit next to April 2025 for a clean year-over-year read.
  2. Break the columns out by month
    In Rows/Columns › Display columns by, choose Months. A Total column is added automatically on the right.
  3. Keep rows collapsed
    Use the Collapse button above the report so accounts roll up to the parent level (e.g. "5000 Direct Labour" as one line). This is what makes it the Summary.
  4. Accrual basis, then run
    Set Accounting method = Accrual and hit Run report.
    Your April 2026 numbers, as a check: Total Income $222,102.66, Total COGS $197,685.33, Gross Profit $24,417.33. If your run matches, every setting above is correct.

Profit & Loss — Detailed

Tab 3 · Detail
Same report as Tab 2 — one control changes
  1. Start from the Summary you just built
    Everything is identical: custom period 04/01/2025–04/30/2026, columns by Months, accrual.
  2. Expand the rows
    Click Expand above the report (the opposite of Collapse). Now every sub-account prints on its own line — "5010 Field wages," "5050 Bonus," "5100 Payroll taxes" — under each parent total.
    Don't confuse this with the report literally named "Profit and Loss Detail." That one lists every individual transaction. Your "Detailed" tab is the monthly summary expanded to sub-accounts, so stay on the Profit and Loss report and just use Expand.

Profit & Loss — by Class

Tab 4 · Segments
Reports › Profit and Loss by Class  (or Profit and Loss, then change columns)
  1. Set a single month
    In General › Report period, choose the one month — 04/01/2026 to 04/30/2026. This report is a snapshot, not a trend.
  2. Put your divisions across the top
    In Rows/Columns › Display columns by, choose Classes. You'll get Construction, Enhancements and Maintenance columns plus a Total.
  3. Add the "% of income" column
    In Rows/Columns, tick % of income. That's your "% of Revenue" column — each line shown as a share of total revenue.
  4. Run and sanity-check the split
    Construction should read $148,742.56 (67%) and Maintenance $73,360.10 (33%) of April income.
    Tip: a "Not Specified" column means some transactions weren't tagged with a class. Chase those down — untagged rows quietly distort every segment margin.

§06

Make it a one-click monthly package

Once each report is customized, you never rebuild it. Save it, group the four together, and have QBO email a branded PDF to you and your accountant automatically.

Save & group the four reports

Turn tonight's setup into a permanent, reusable set.

  1. On each finished report, click Save customization.
  2. Name it plainly — "01 Balance Sheet," "02 P&L Summary," etc.
  3. Under Add this report to a group, create one group: "Monthly Board Package."
  4. Find them any time under Reports › Custom reports.

Auto-email it every month

The whole group goes out on a schedule — no one has to remember.

  1. Go to Reports › Custom reports and find your group.
  2. Open Edit on the group › Set the email schedule = On.
  3. Set it for the 5th of each month (after close), recipients = you + your accountant.
  4. Attach as Excel and PDF so both are on file.

Build a branded report package

QBO's presentation-ready reports add a cover page and notes — this is the "elite" look.

  • Open Reports › Management reports (a.k.a. presentation-ready).
  • Create a template; add a cover page with the VIL logo and a table of contents.
  • Drop in Balance Sheet, both P&Ls, and P&L by Class.
  • Add a short executive summary note up front, export one clean PDF.

Add the three reports pros always include

A complete package is more than a P&L. Add these to graduate from good to elite.

  • Statement of Cash Flows — profit isn't cash; this shows the difference.
  • A/R & A/P Aging Summary — you carry $128K receivable and $142K payable; watch the aging.
  • Budget vs. Actuals — set a budget in QBO, then this report grades every month against it.
